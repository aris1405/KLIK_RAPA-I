Untuk aplikasi KLIK RAPA'I, saya menyarankan menggunakan sistem transisi Hybrid Smooth Transition (Partial Render + Fade).

Tujuannya bukan membuat semua elemen bergerak ketika pengguna berpindah halaman, tetapi memberikan kesan aplikasi profesional, halus, dan responsif tanpa membuat dashboard berkedip.

Prinsip utamanya:

- Sidebar tidak boleh menghilang atau dimuat ulang saat berpindah menu.
- Navbar/topbar harus tetap diam dan stabil.
- Hanya bagian konten utama yang mengalami transisi.
- Tidak boleh ada efek layar putih atau dashboard berkedip.
- Animasi cukup singkat, sekitar 150–220 ms.

## 2. Bagian yang perlu diperbaiki pada kode sekarang

Saya sudah memeriksa struktur `KLIK_RAPAI_05.html`. Sebenarnya sudah ada fondasi transisi yang bagus, tetapi beberapa bagian perlu disempurnakan.

| Kode saat ini             | Kondisi                       | Rekomendasi                               |
| ------------------------- | ----------------------------- | ----------------------------------------- |
| `.content-enter`          | Memicu animasi konten         | Ganti dengan transisi khusus konten       |
| `.listItemIn`             | Item bergerak satu per satu   | Hilangkan animasi berulang                |
| `.stats .stat`            | Animasi saat dirender         | Jangan diputar ulang setiap navigasi      |
| `.page-enter`             | Menggerakkan seluruh halaman  | Batasi untuk halaman publik               |
| `updateDashboardChrome()` | Memperbarui elemen topbar     | Pertahankan, jangan render ulang topbar   |
| `.bell .dot`              | Pulse terus-menerus           | Hilangkan pulse                           |
| `.sidebar`                | Sudah memiliki transisi lebar | Pertahankan untuk buka/tutup sidebar saja |

Ada satu hal penting: kode sekarang sudah menggunakan partial update untuk navigasi dashboard. Ini bagus karena sidebar dan topbar tidak perlu dibangun ulang ketika berpindah antarmenu. Sebaiknya mekanisme ini dipertahankan.

## 5. Aturan teknis agar dashboard tidak berkedip

Ini bagian paling penting untuk diterapkan.

1. Jangan menggunakan `innerHTML` pada seluruh `#app` ketika pengguna berpindah antarmenu dashboard.
2. Jangan menghapus dan membuat ulang elemen sidebar maupun topbar.
3. Hindari `offsetHeight` untuk memaksa animasi ulang pada setiap pergantian halaman.
4. Jangan menjalankan animasi statistik setiap kali navigasi.
5. Jangan menggunakan animasi opacity berulang pada navbar, sidebar, jam, atau notifikasi.
6. Jam cukup memperbarui teks waktunya, bukan seluruh elemen topbar.
7. Grafik hanya diperbarui ketika datanya berubah atau halaman grafik dibuka.
8. Gunakan `prefers-reduced-motion` untuk pengguna yang mengurangi animasi.

2. Tahap 2 — Transisi konten

3. Tahap 3 — Interaksi

   Memperhalus modal, dropdown, tombol, tab, dan notifikasi.
4. Tahap 4 — Login dan logout

   Mempertahankan animasi layar penuh hanya pada proses autentikasi.
5. Tahap 5 — Optimasi

   Menguji navigasi cepat, pergantian role, tampilan HP, grafik, serta kondisi jaringan lambat.
